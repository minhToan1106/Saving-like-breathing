The verdict, as the code will do it

Rules in rules.js

limit = max(0, stake − penalty)
penalty = $0.50 if yesterday was a loss, else $0
actual spent = max(0, morning + income today − night)
Win if actual spent ≤ limit → saved += limit − actual spent

All money is stored in cents (300 = $3.00), so $3.00 − $0.50 is always exactly $2.50. A tests.html page checks the PRD's examples with PASS/FAIL.

Catch-up when the app opens

Bet Monday, forgot to settle, opened Wednesday:

Mon → loss (not settled) · Tue → loss (no bet) · streak 0 · today shows the $0.50 penalty notice. A new month resets savings in the same check. Night opens at 7 PM.

Look and feel

Hand-drawn gothic

IM Fell English headings · Patrick Hand text · SVG wobble on borders · generated paper grain · layered pencil-style shadows. No game assets. No gradients, glass or generic rounded cards.

Day / Night

Day: sepia paper, brown ink, rust accent. Night: near-black paper, parchment ink, ember accent. Grid: muted green / red / gray. One toggle flips every color variable.

Run it & record it
